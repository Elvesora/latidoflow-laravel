# Security Policy

## Supported versions

Security fixes are provided for the latest patch release in the supported release line. Users should upgrade to the latest available patch before reporting a vulnerability.

| Release line | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include credentials, tokens, customer data, serialized job payloads, command arguments, exception text, or response bodies in a report.

Use the repository's [private vulnerability reporting form](https://github.com/Elvesora/latidoflow-laravel/security/advisories/new) to submit a private GitHub security advisory.

Include the affected version, impact, reproduction steps, and a minimal proof that contains no live secrets. Maintainers will acknowledge the report, investigate it, and coordinate disclosure through the private advisory.
